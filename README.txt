MOVIE WATCHLIST — REACT STARTER

1. Create a Vite React project:
   npm create vite@latest movie-watchlist -- --template react
   cd movie-watchlist
   npm install

2. Replace the matching files in the project's src folder with these files.

3. Start the development server:
   npm run dev

Complete the TODOs in src/App.jsx: state, adding movies, removing movies, and
rendering saved movie cards. Official React learning guide: https://react.dev/learn
